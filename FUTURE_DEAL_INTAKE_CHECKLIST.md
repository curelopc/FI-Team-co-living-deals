# Co-Living Deal intake standard

Apply to every eligible feed property, not only the current three. Preview-only work never writes Sheets, changes sharing, publishes, buys services or contacts anyone.

## Evidence and proposal
- Confirm exact active eligibility, valid coordinates and normalized address; overlay denser evidence only on address match. Read by header, not position.
- Preserve current listing price, square feet and beds/baths separately from edited purchase scenario and proposal.
- Inspect authentic available plans and listing photos. Record exact drawing identity, provenance, level and each unique numbered bedroom. Never erase annotations to fabricate a Before. Different levels are not a comparison.
- Supply `ProposalInventory` to `standardScenario` for new proposals: nonempty authentic source reference, unique positive room numbers, actual level, evidence and truthful bath access (unknown bath is allowed). Invalid/missing proposals remain Needs review; listing counts alone never become drawn rooms.
- Best-fit redlines use straight red walls, deliberate common-hall door gaps, red C closets and continuous shared stair/utility/bath access without bedroom pass-through. This is a concept, not legal certification. Do not wait for measurements or invent feasibility.
- Owner window scope: no upstairs proposed work; basement new/upgrade work uses standalone plain W only. No number attached, E or question mark on drawing. Inspect each property's own photos; uncertain matches and compliance stay in the collapsed explanation. Never copy Elmira coordinates or declare unreviewed windows complete.
- Parking uses the property's own uncropped attributed evidence. Distinguish observed cars, estimated/tandem positions and shared curb. Preserve neighbor cuts, sidewalks and egress; unknown clearance remains unknown. No fabricated dimensions or legal total capacity.

## Financial intake
- One supported numbered bedroom = one default/Reset rent row. Missing proposal never defaults to ten. Source rows without proposal are explicitly not-drawn scenarios. Additions up to sixteen say Scenario / not drawn.
- Per-room actual source rents win when matching numbered rooms; otherwise use the property's labeled estimate. Missing rent uses the property estimate where available, otherwise a declared editable $800/month planning estimate, never a verified zero. Fraser770/Grove830 and Elmira830 primary/670 shared are not universal rates.
- Defaults only where actual property evidence is absent: owner water20/gas10/electric50 per active room; internet100/trash70 fixed; tenant utility income80/room separately; cleaning150/lawn80/repairs250/reserve250; management16% gross and vacancy5%; maintenance/security150 flat property/month, editable. Remove all PadSplit variants.
- Preserve actual source expense amount and monthly/annual normalization. Historical PDF assumptions are not current actual expenses. Preserve actual insurance; otherwise tax/month+200 is an editable labeled estimate. Missing tax uses a declared 0.6% purchase-price annual allowance; insurance uses tax/month + $200 unless actual insurance is supplied.
- Craig t56: preserve every supported debt, rate, budget and source expense. Fill only absent financial values with finite editable estimates and collapsed basis/units/frequency. Assume no other income/private financing/credit, and no HOA only without source evidence. Credit0 never implies invoice authorization. Preventive pest allowance35/month ($420/year), not a quote. Missing holding uses two pre-lease months of existing mortgage P&I plus tax/insurance/utilities and applicable HOA/pest/septic/private carry, excluding renovation/closing/furnishings/management/vacancy/reserves. It is upfront cash only, not an additional stabilized monthly debt charge. Future missing financing uses listing price or explicit500000 planning price, rate7.5%,30years,20%down, closing2%, and missing budget3000/bedroom+16000 furnishing/contingency; none claims actual evidence. Keep source renovation budget and informational concept allowances separate, never add allowances to CapEx or sum total rows plus items.
- Home and detail use `modelSummary` over the same root-owned session inputs. Missing physical proposal remains unverified; financial working assumptions show Estimated; invalid or cleared user inputs block returns; partial invested denominator never creates CoC. Negative user financial values and rents remain visible and invalidate income-dependent totals.
- Session edit -> Home -> Back preserves rows and all dependent metrics; Reset clones the original evidence-aligned seed. No persistence across visitors/reloads.

## Presentation and acceptance
- Authentic FI Team logo, Co-Living Deal, shared MLS carousel (max30), compact navigable cards/map. Carousel controls/drag and map pan/zoom do not navigate.
- Long source, budget, photo/window and parking evidence belongs inside initially collapsed keyboard-accessible Show explanation. Keep concise current/proposed/missing truth visible.
- Audit every current eligible/exposed ID from a fresh feed. Record counts, rents, source/estimate basis and plan/photo/window/parking review status.
- Run generic fixtures with/without proposal, rent and financial facts, source precedence, default expense factors, flat fee, no PadSplit, card/detail parity and session/reset. Check desktop/mobile and Enter/Space disclosures, images and runtime errors.
- Review actual screenshots before returning direct full HTTPS URLs. State exactly what was inspected and remaining source/hosted gaps. No claim of legal bedrooms, egress or parking certification.

## Large areas
- Consider more than one bedroom in a large open area, but count a room only if it is a unique enclosure with sensible proportions, a closet C, an exterior window concept and its own door gap to common space. Never count a room that blocks stairs, baths, utility, exits or another room's access.
